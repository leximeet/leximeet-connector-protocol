<details>
<summary>查看和编辑 Mermaid 源码</summary>

[图源文件](diagrams/figure-78f83210b9-01.mmd)

```mermaid
sequenceDiagram
  participant U as 用户
  participant B as Browser 可信后台
  participant D as Desktop
  B->>D: hello(clientInstanceId, displayName)
  D-->>B: 桌面实例、名称、合同与能力
  U->>D: 一键连接已发现插件（也可在插件发起）
  D->>D: 建立指定客户端的 120 秒邀请
  B->>D: getConnectionStatus
  D-->>B: pending 邀请（秘密票据只进后台）
  B->>U: 真正的插件确认窗口
  U->>B: 确认连接
  B->>B: 先持久记录邀请、停写并封存 A
  B->>D: pair(invitationId, invitationToken, clientInstanceId)
  D-->>B: 原子签发配对凭据与会话
  B->>D: getWorkspace 验证 owner
  B->>B: 切换为读 B、采集写 C
  Note over B,D: 双方显示成功；A 从不上传
```

</details>

```mermaid
  [*] --> Independent
  Independent --> Preparing: 用户选择连接并冻结独立入口
  Preparing --> Connected: 配对授权后持久切换 owner
  Preparing --> Independent: 确认未接受且取消/过期；保持登出
  Connected --> Reconnecting: 连接丢失
  Reconnecting --> Connected: 恢复同一授权与工作区
  Connected --> Independent: 用户明确断开并恢复独立
  Reconnecting --> Independent: 用户明确恢复独立并隔离未知操作
```
