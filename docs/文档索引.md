# 文档索引

## 接入开发

初次接入时，建议先读[接入实战](接入实战.md)，了解如何替换核心适配器、完成真实确认与采集、处理未知结果并验证链路。它提供操作指南，具体行为仍以下面的冻结规范为准。

1. [架构与接入](架构与接入.md)：核心适配器、Native 绑定和读写边界。
2. [自动发现与连接邀请](自动发现与连接邀请.md)：双方发起、插件确认、票据恢复。
3. [连接与恢复](连接与恢复.md)：A/B/C 资料、断线、明确断开和旧响应隔离。
4. [配对与契约身份](配对与契约身份.md)：身份、会话、权限与兼容协商。
5. [接口规范](接口规范.md)：完整方法、参数与错误。
6. [共享数据模型](共享数据模型.md)：词身份、范围、来源和原子采集。
7. [双向宿主能力](双向宿主能力.md)与 [Browser 扩展](extensions/browser.md)：可选能力、页面授权和动作回执。
