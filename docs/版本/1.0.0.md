# LexiMeet Connector Protocol 1.0.0

LMCP 的首个正式本机连接合同。插件负责遇见和采集，Desktop 提供权威资料与学习核心；本仓提供规范和参考验证，不交付应用运行时 SDK。

## 正式合同

- 19 个桌面方法，其中 16 个基础必需方法；7 个可选反向宿主方法。
- 自动发现、连接邀请、插件真实确认、配对、短会话、授权范围、临时失联恢复与明确断开。
- 稳定词身份、幂等采集、事务回执、丢 ACK 查询、重启恢复及撤权边界。
- 插件独立资料在连接时封存；连接期间直接使用桌面资料，断开才恢复独立资料，不隐式合并。
- 个人批注仅使用 `note`，公共词典释义独立；不定义个人释义或用户标签管理。

## 发行附件

[GitHub Release](https://github.com/leximeet/leximeet-connector-protocol/releases/tag/1.0.0) 提供合同物料归档、完整源码与参考验证归档、`RELEASE-MANIFEST.json` 和 `SHA256SUMS`。

合同包包含原始规范、Schema、机器合同、结构样例与许可证，适合固定消费快照；源码包包含文档、工具、测试和依赖锁。下载后执行 `shasum -a 256 -c SHA256SUMS`，按清单核对源码提交、合同摘要及每个归档的实际长度。

标签 CI 在 Node.js 22/24 上分别执行格式、合同、参考测试和归档验证；发布任务复用已经验证的归档，再检查精确标签来源。17 项规范原字节和共享模型摘要保持冻结，不因发布说明、Release 元数据或维护文档更新而改写。

## 验证边界

结构样例、参考行为与发行归档测试不等于真实宿主验收。Browser/Desktop 的连接组合、平台、生产字节和实际行为由消费端流水线分别记录；IDEA、VS Code、WPS 等尚属路线。正式协议演进按兼容政策处理，已公开版本标签不移动。
